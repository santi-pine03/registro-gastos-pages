Política de privacidad

registro-gastos es una herramienta de uso personal. Esta página explica qué datos usa y cómo.

Datos a los que accede

Con el permiso de solo lectura de Gmail (gmail.readonly), la herramienta busca únicamente los correos enviados por DAVIbankInforma@davibank.com y extrae de ellos el nombre del comercio, el monto y la fecha de cada compra. No lee otros correos, no envía, modifica ni elimina mensajes.

Cómo se usan

Los datos extraídos se guardan en un archivo de Excel en el computador del dueño de la herramienta. Para clasificar un comercio desconocido, el nombre del comercio y el monto pueden enviarse a la API de Claude (Anthropic); no se envía el contenido completo del correo ni otros datos personales.

Almacenamiento y compartición

Las credenciales de acceso y los datos se guardan solo de forma local. No se venden, no se comparten con terceros (salvo lo descrito para la clasificación) y no se usan con fines publicitarios.

Revocar el acceso

El acceso a Gmail se puede revocar en cualquier momento desde myaccount.google.com/permissions.

Uso de datos de Google

El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
